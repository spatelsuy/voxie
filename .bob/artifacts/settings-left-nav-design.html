Settings — Left Nav Redesign
The content area stays the same. Only the navigation model changes — sections are now chosen from a fixed left pane instead of scrolling past them.
Left nav pane NEW

130 px wide, fixed. Each section (Recording, AI/A2T, Appearance, Tasks, Storage, About) is a tappable item with an icon + label. The active item gets a left accent border and blue label.

Content panel

Shows only the rows for the selected section — no more scrolling through all groups at once. The section title stays at the top of the panel as a header.

What stays the same
  • Row card style (icon · label · control)
  • Toggle, stepper, select controls
  • Top header bar with logo
  • Bottom tab bar
  • All existing settings & logic
Mobile behaviour

On narrow screens (< 400 px) the nav labels can be hidden, showing icons only, to keep the content area wide enough to read.
